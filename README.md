# Supply Chain & Inventory Analytics

An end-to-end data analytics project focused on **supply chain, inventory, supplier, logistics, and product performance** using Python, Pandas, MySQL, SQL, Power BI, and DAX.

The project follows a complete analytics workflow: raw data cleaning → database preparation → SQL analysis → KPI development → interactive Power BI dashboard.

---

## 📊 Project Overview

Supply-chain operations involve multiple interconnected factors such as inventory levels, product demand, supplier lead times, shipping costs, transportation modes, and product quality.

This project analyzes these factors to answer practical business questions such as:

- Which product types generate the most revenue?
- Which products have low inventory levels?
- Which suppliers contribute the most revenue?
- Which suppliers have longer lead times?
- Which shipping carriers have higher costs?
- Which transportation modes are more expensive?
- Which suppliers have higher defect rates?
- Which supplier locations generate the most revenue?

The goal is to turn raw operational data into **clear, decision-oriented business insights**.
